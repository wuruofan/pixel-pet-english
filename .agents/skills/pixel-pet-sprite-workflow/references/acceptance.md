# 验收清单（用户历史反馈固化的坑）

每次出新版 sprite 或修改动画后，逐项检查。任何一项不过关都不要提交。

## A. mmx 出图

- [ ] **teen 必须完全正面对称脸**（左眼=右眼大小、鼻嘴居中）——用户多次因侧脸要求重新生成
- [ ] 单条尾巴（dragon 出过双尾巴）
- [ ] 无手臂 / 无背部刺残留（dragon 强调 no arms / no spikes 仍可能出）
- [ ] 无 `ears poking out`（蛋形会变瓶子开口）
- [ ] 背景纯色、底部无复杂阴影

## B. 脸部

- [ ] **鼻嘴间距 ≥ 1px**（kid 鼻 2px 嘴 3px 曾贴在一起）
- [ ] **嘴宽 kid ≤ teen ≤ adult**；**excited 嘴宽 ≤ adult 的嘴宽**（kid 嘴曾比 adult 还大，很怪）
- [ ] 眼睛位置对称（左右眼 x 镜像、y 相同）；与 mmx 原图真实位置对齐（不是猜）
- [ ] 腮红在**白色口鼻区**两侧、**y 低于眼睛**（不能盖在橙色/绿色毛上）
- [ ] 嘴型统一 ω 风格，三阶段同款（kid/adult 嘴型曾不一致）
- [ ] 擦除区域残留检查：原图眼/鼻/嘴/鼻孔/舌头阴影清干净（adult 曾残留闭眼+鼻孔+嘴巴）
- [ ] 脸部轮廓保持圆润（teen 左下角曾成方角，补 5 像素圆润）

## C. 动画

- [ ] **走路 = 跳跳蹦蹦**（offset_y 上下起伏），不做腿部差分（已明确否决）
- [ ] 走路时**五官跟随**（offset_y != 0 时 face 锚点/擦除区域全部跟着偏移）
- [ ] **吃饭三帧不同表情**（eat-0/1/2），五官跟随头部移动（用户反馈过"头动了表情没动"）
- [ ] **洗澡气泡左右交替**（wash-0 右 / wash-1 左，跟 dog 一致）
- [ ] **气泡每侧 ≥5 个**、大小不一（2x2/3x3）、位置分散头部外侧/上方，**勿贴耳**（fox 曾因贴耳太小看不清）
- [ ] 状态实验台实景演示（tbPlay）也播多帧动画（wash 交替、eat 表情变化）
- [ ] Zz 两个（大+小错开），**不与耳朵重叠**（fox 曾重叠）

## D. 运行时

- [ ] 所有帧背景透明（无奶油色/背景色残留）
- [ ] 底部无地面阴影残留（检查孤立像素，flood fill 可能漏）
- [ ] 28 pose 帧全部存在且非空
- [ ] PET_FRAMES 每个 expr 的每个 stage 映射正确（0=蛋 1=kid 2=teen 3=adult）
- [ ] `node --check src/app.js` 通过
- [ ] `node scripts/build.js` 成功
- [ ] 浏览器实际渲染检查：表情切换、走路、洗澡、吃饭动画正常

## E. 历史失败教训（为什么这些坑存在）

| 阶段 | 失败 | 根因 | 对策 |
|---|---|---|---|
| fox v1-v6 | PIL 手绘 polygon 不像狐狸 | 手绘不可控 | mmx 出图 + 程序差分 |
| fox v6 | 表情画在脸外、旧眼残留 | 锚点表把鼻子当左眼、擦除区用错色 | 按真实像素逐点校准；擦除用毛色 |
| dragon teen v1 | 双尾巴 + 脸颊刺镜像后成不雅形状 | 原图侧脸 + 程序乱改 | 重新出图（v4 正面） |
| dragon teen v2/v3 | 侧向脸难差分 | mmx 生成侧脸 | v4 prompt 加 POKEMON/SYMMETRICAL |
| dragon adult | 右侧气泡与脑袋重叠 | 气泡位置没按头部宽度定制 | 每阶段独立气泡表 |
| fox walk | 腿分叉到胸口、抠图缺像素 | 腿部差分移动区域定义不准 | 放弃腿部差分，改跳跳蹦蹦 |
| dragon eat | 头动了表情没动 | offset_y 只移身体不移五官 | _offset_face 递归偏移锚点 |
| fox wash | 实景演示单侧气泡 | tbPlay 不启动多帧动画 | tbPlay 调用 tbStartAnim |
